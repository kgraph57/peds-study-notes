# 小児科 Visual Study Notes

小児科専門医試験の学習用にまとめた、図解中心の静的サイト。

- 10分野・45点の病態図、比較表、初期対応アルゴリズム
- 領域検索、習得状態フィルター、図表だけの復習モード
- 各図に一撃所見、試験の引っかけ、30秒復習、学会資料リンク
- 既存の「未／あやしい／覚えた」、自分用メモ、進捗保存を維持
- モバイル優先、ダークモード、キーボードフォーカス、reduced motion対応
- 公開URL: https://peds-study-public.vercel.app

## 注意
- 個人の学習用にまとめたオリジナル要約です。
- 診療上の判断は必ず一次資料・診療ガイドラインを参照してください。内容の正確性・最新性は保証しません。

## デプロイ
```bash
npm test
vercel deploy --prod
```

`main` への push 後も、公開反映は `vercel deploy --prod` で明示的に確認します。
